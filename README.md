# dce

**多视图差分层。** 把「多个视图之间的结构性分歧」算成可核对、可证伪的量。

> **Consensus ≠ Truth** · **Divergence ≠ Error**
> 输出全部属于 `derived structure`，不是 `ground truth`。

家族位置：`Scaffold`（结构空间）→ `arena`（交互层分歧）→ **`dce`（视图层分歧）** → …

---

## ⚠️ 先说清楚成色

**这是能算、且能算错的东西，不是已验证的结论。**

| 项 | 实际情况 |
|---|---|
| 是什么 | 派生结构层。输入是**已映射到同一节点空间**的多份视图，输出是**差异及差异的类型**。不产出真值 |
| 依赖 | **零第三方**（`checks/scope.py` 逐个文件扫过 import）。标准库 + 纯内存 |
| 测试 | **161 条断言 / 97 条测试，红 0**（套件约 2 分半） |
| 状态 | **第一步已过线**；**第二步已验收** —— 真实数据上**往返 100%**、无外部输入 |
| 不做的 | 曲率 / 神经场 / latent field / 自动生成节点 / ontology alignment / 真假判断 / 模型评分 / 权威排序 / 长期记忆 / 遗忘 / 主体性 / 实时模型构造 |
| 一句话的诚实版 | 与「并集 + 频次」的**划分完全相同**（定义使然）。多出来的**只有类型** —— 是**表达力**的增量，**不是准确率**的增量 |

## 它只回答三句话

    这些视图在哪里相同？在哪里不同？**差异属于什么类型？**

**第三句是唯一比「并集 + 频次」多出来的东西。** 五类差异：

    共识 · 矛盾 · 替代解释 · 缺失 · 精炼

而「类型真的多出了东西」可量化 —— 用粗糙集的依赖度：

    γ = 1  ⟺  类型判定完全由「单元出现在哪几个视图」决定
           ⟺  类型没有携带成员关系之外的任何信息

### 已经证明到哪一步

    ✅ 第一步：视图层能区分
       构造材料（有已知 ground truth）          γ = 0.2105
       公开论辩数据 Perspectrum（**非自造**）    **134 / 752** 个 claim 上 γ < 1
       独立对账：矛盾 **217 条**，两条互不相干的数法给出同一个数

    ✅ 材料里真的出现了矛盾（这一步的前置）
       判据：**存在一个有序对，在两个视图里挂了互斥的关系**

    ✅ 第二步：**视图本身足够支撑检索**（已验收）
       产物是**索引**（面合取 → 差异记录集合）。公开数据上实测：
       覆盖 **100%** · 往返 **100%** · 不塌 · 可枚举 · 确定性 · **无外部输入**
       ⚠️ 而**索引不压缩**（键/记录 ≈ 0.9×，它是**重新编码**不是摘要）——
       压成「几张抽象视图」是**后续抽象层**的事，**不在本层兑现**
       ⚠️ **相似不出现 —— DCE 不做匹配，那是检索系统的事**

---

## 它不是什么

- **不解决 semantic alignment**。节点身份 = id 字面值，**不做同名归并**
  （⚠️ **携带**一个标签不是归并 —— 两件事，别混）
- **不判真假、不打分、不排序**。排序即推荐，本层不做推荐器
- **不做匹配/相似**。把一段处境映射到索引的键是检索系统的事
- **不接上游的现状**。Scaffold 缺的恰好是判定分歧必需的东西（边的种类与方向、
  多 source 槽位），所以不追求与它适配，材料按判据自己造

## 5 分钟上手

```bash
git clone https://github.com/aic-123/dce.git && cd dce

python -m checks            # 全部检查。三态：红 / 过 / 跳过 —— **跳过不等于通过**
python tests/run_tests.py   # 97 条测试

python -m checks.mvp        # 只看「第一步过线了吗」
python -m checks.index      # 只看索引：四条性质 + 最小依赖集 + 充分性
python -m checks.acceptance # 只看第二步的验收：真实数据上的往返
```

**零依赖**，两个 runner 都自带，不装任何东西就能跑。
公开数据（`countries`、Perspectrum）**不在仓库里**；缺了相关检查会报**跳过**，
而报告里「跳过」与「过」**分开写**。

```

analysis/     共识 · 分歧 · 焦点 · β · 概念格 ·

metrics/      覆盖 · 压缩 · 粗糙近似                   373 行
checks/       检查（含验收）                        5,040 行   **比被检查的层还大**
generators/   合成语料 · 拓扑 · 立场材料             1,108 行
adapters/     scaffold · arena · countries ·
              perspectrum                           1,055 行   §十八 的边界层

```

**检查层比被检查的分析层大，这是有意的** —— 那不是设计偏好，是代价换来的：
每一条教训都曾经让检查全绿而结论是错的。

## 已知的未做（不是漏了）

| 没做 | 理由 |
|---|---|
| 接真实 LLM | 第一步用合成 ground truth + 公开数据即可，不需要模型 |
| 第二步的**匹配** | 判据裁定：**相似不进本层**，留给检索系统 |
| 压成「几张抽象视图」 | 本层的索引**不压缩**（键/记录 ≈ 0.9×，是重新编码）。那是**后续多层抽象**的事，**不在本层兑现** |
| 逐概念的零分布 | 现在只有**聚合统计量**的判据；逐概念需先定「随机化之间哪个概念算同一个」 |
| 三级以上的概括 | 「有用层」判据已能给出区间，产物现在到两级 |
| 与 Scaffold v0.0.3 适配 | 它缺的正是判定分歧必需的东西。`adapters/scaffold.py` **保留**（记着四条不符的逐条更正），**不再当正确性目标** |
